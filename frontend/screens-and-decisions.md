## 와이어프레임과 다르게 한 점

와이어프레임에 없거나, 그대로 따르면 동작이 모호해지는 곳만 적는다.

**문서·편집**
- 밑줄은 Markdown 에 표준 문법이 없어 `++text++` 로 저장한다(DOCUMENT_EDITING_PROPOSAL §3.2 와 다름).
- 에디터 툴바 기본값은 토큰 값(14px · 1.5)을 따른다. 와이어프레임 라벨은 16 · 1.78 이다. 어느 쪽을 기본으로 할지 정해 주면 토큰 하나만 바꾸면 된다.
- PDF 내보내기는 브라우저 인쇄로 만든다. DOCX·HWP 는 서버 몫이라 mock 에서 안내만 한다.
- 문서 옆 메모는 편집 영역이 640px 보다 좁아지면 접히고 "다시 열기"는 아래 도킹으로 연다.

**사이드바·파일**
- 파일 행 메뉴에 "옆에 열기"(분할 보기 진입점)를, 파일 휴지통 이동에 확인 대화상자를 더했다.
- 즐겨찾기 영역 메뉴는 "섹션 추가"만, 파일 영역 메뉴에는 "이름 변경"이 없다(대상이 영역 자체라서).

**작업공간 화면**
- "최근에 연 파일"은 열람 기록 API 가 없어 최근 수정 순으로 대신한다.
- 검색 결과에서 일치한 글자를 굵게 표시한다.
- 프로젝트 설정 입력란에 글자 수(40·200)를 보여 준다.
- 도움말에서 가이드로 들어가면 탭 이름이 "사용 가이드"로 바뀐다(와이어프레임 078).
- 메모 패널의 작품 메모 카드는 누르면 그 자리에서 펼쳐 편집한다. 카드 제목은 메모 제목, 없으면 본문 첫 문장이다.
- AI 챗 세션 삭제 확인은 전체 화면 모달이 아니라 챗 패널 안에서 연다(와이어프레임 018 모양).
- 버전 삭제는 확인 대화상자를 거친다(와이어프레임에는 휴지통 아이콘만 있다).

**그래프·타임라인**
- 엣지에 방향 화살표가 있다(관계를 가진 문서 → 대상 문서).
- 노드를 누르면 선택 패널을 연다. 걸러서 1-hop 만 남기는 실험 레포 동작은 쓰지 않는다.
- 노드가 150개를 넘으면 원고·캐릭터·이벤트만 켜고 시작하며 안내 띠를 띄운다.
- 타임라인 회차 머리글은 한 번 누르면 선택, 두 번 누르면 그 원고를 연다. 원고는 열이므로 즐겨찾기한 원고는 즐겨찾기 줄에 나오지 않는다.

**기타**
- 테마 선택은 와이어프레임에 없어 계정 메뉴에 "화면 테마"(시스템·다크·라이트)로 넣었다.
- 토스트는 오른쪽 위에 뜬다.
- 시드 데이터는 새로 쓴 이야기다(ORV 픽스처 미사용).

## 남은 결정 사항

1. **폴더 모델** — `TABLE_AND_LOGIC.md` §4.1 은 사용자가 만들 수 있는 폴더를 에피소드로만 제한한다. 지금 프론트는 와이어프레임(27·86·161–166)대로 사용자 섹션과 일반 폴더를 만들고 옮길 수 있다. 제안을 따르면 사이드바의 섹션·폴더 메뉴와 드래그 이동 일부를 걷어내야 한다.
2. **최신화 모달 편집** — 모달에서 덩어리 밖을 직접 고치지 못하게 한 것은 앞서 정한 결정인데, `TABLE_AND_LOGIC.md` §7.5 는 양쪽 직접 편집과 초안 저장(`PATCH /refresh-document-drafts/{id}`)을 전제로 한다. 어느 쪽으로 갈지 정해 주면 맞춘다. 초안 저장만이라면 현재 `MergeState` 를 그대로 보내면 된다.
3. **3-way 표시와 STALE** — base 스냅샷을 받아 충돌 구간을 따로 칠할지, 반영 직전 문서가 바뀐 STALE 상태를 어떤 화면으로 보여 줄지(와이어프레임 없음).
4. **메모·즐겨찾기 서버 범위** — 새 제안은 둘 다 이번 범위에서 뺐다. 로컬 저장으로 둘지, API 를 추가할지.
5. **툴바 기본값** — 14 · 1.5(토큰) 대 16 · 1.78(와이어프레임 라벨).
6. **외부 연결 값** — `public/config.json` 의 `feedbackUrl`·`privacyPolicyUrl`·`termsOfServiceUrl` 이 비어 있다. 비어 있으면 피드백 열기는 실패 화면(081)으로 간다.
7. **가이드 콘텐츠 출처** — 정적 번들로 둘지 서버·CMS 에서 받을지. 정적이면 `HelpService` 를 걷어내면 된다.
8. **병합 시점** — 작업은 `feat/wireframe-sync-foundation` 에만 올라가 있다. `main` 에 합치면 S3·CloudFront 배포가 바로 돈다.
