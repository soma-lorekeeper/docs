# 그래프 최신화 — 미리보기

> 작성일: 2026-10-08
> 상태: `loresentry-frontend` #40. AI 생성만 규칙으로 대신한다.

실제 API 모드에서 "그래프 최신화 (준비 중)" 이던 버튼이 동작한다. 사용자의 실제 원고와 설정 문서를 읽고,
고른 내용을 실제 문서에 저장한다. **갱신안을 쓰는 부분만** AI 대신 규칙이 맡는다.

## 1. 나눈 곳

| 부분 | 파일 | 지금 | 실제 AI 가 붙으면 |
|---|---|---|---|
| 갱신안 생성 | `src/services/api/refresh-proposals.ts` | 규칙 | graph-rag 호출로 바꾼다 |
| 실행 상태(추출 중·검토 대기·반영됨) | `src/services/api/refresh.ts` | 브라우저 `localStorage` (`loresentry.refresh.<projectId>`) | content `refresh_runs`·`refresh_document_drafts` 로 옮긴다 |
| 반영 | `src/services/api/refresh.ts` | 실제 API (`GET/PUT /files/{id}/content`, `POST /files/{id}/versions`, 파일 만들기) | 서버가 한 번에 반영하는 API 로 바꿀 수 있다 |
| 검토 화면 | `src/features/graph-refresh/*` | 그대로 | 그대로 |

포트(`RefreshService`: `current`·`start`·`apply`·`discard`)와 화면 모델(`RefreshRun`, `RefreshProposal`)은 mock 과
같다. 서버가 생기면 `services/api/refresh.ts` 를 HTTP 어댑터로 바꾸고 `preview` 표시를 뺀다.

## 2. 규칙 (갱신안 생성)

입력은 최근에 고친 원고 3편과 설정 문서 목록이다. 사용자가 쓴 문장만 쓴다. 지어낸 사실은 넣지 않는다.

| 제안 | 조건 | 내용 |
|---|---|---|
| 설정 문서 수정 (최대 5개) | 문서 제목이 원고에 나온다. 많이 나온 것부터. 잠긴 문서는 뺀다 | 그 문장을 본문 끝에 `‘회차’에서: 문장` 으로 덧붙인다. 설명이 비어 있으면 채운다. 그 원고, 같은 문장에 함께 나온 설정 문서와 관계를 잇는다 |
| 이벤트 문서 추가 (최대 1개) | 원고에 이어진 이벤트가 없고, 회차 이름과 같은 이벤트도 없다 | `<회차 이름>에서 생긴 일`. 첫 두 문장, 원고·등장 설정 문서와의 관계 |

한글 제목은 조사가 붙어도 찾고(`서윤은`), 로마자 제목은 단어 경계를 본다(`Theo` ≠ `Theodore`).
덧붙이는 문구는 화면 언어를 따른다.

## 3. 반영

1. 결정하지 않은 제안이 있으면 거절한다.
2. 고칠 문서를 다시 읽어 `revisionNo` 가 추출 때와 다르면 **아무것도 쓰지 않고** 거절한다("추출 뒤에 수정됐어요").
3. 문서마다 `그래프 최신화 반영 전` 이름의 버전을 먼저 남기고 `If-Match` 로 저장한다. 완료 토스트의 "반영 전 상태는 버전 기록에 남아 있어요" 가 이 버전이다.
4. 새 문서를 만들고 내용을 저장한다.

- **관계 쌍.** content 는 관계를 문서 쌍마다 한 행으로 두고, 저장한 문서의 관계 전체를 바꾼다. 그래서 앞 문서가 이은 관계를 뒤 문서의 예전 목록이 지우지 않게, 앞에서 생기거나 끊긴 쌍을 뒤 문서 저장에 반영한다.
- **중간 실패.** 반영한 제안을 기록해 두고, 다시 누르면 남은 것만 반영한다.
- 현재 버전 그대로 둔 문서는 저장하지 않는다.

## 4. 화면에 더한 것

- 목록 아래 "미리보기 제안이에요…" 한 줄(`RefreshRun.preview`). 실제 AI 가 붙으면 지운다.
- 제안이 없을 때 "새로 반영할 내용이 없어요" 창. 확인하면 실행을 지운다.
- 추출이 실패하면 사이드바에 토스트.
- 휴대폰 폭(≤720px): 전체 화면, 문서 목록은 위쪽 가로 줄, 두 버전은 좁은 두 칸.

## 5. 한계

- 실행 상태가 브라우저에 있다. 다른 기기·브라우저에서는 이어서 볼 수 없다.
- 규칙은 이름이 그대로 나온 문장만 찾는다. 별칭·대명사·요약·모순 찾기는 실제 AI 몫이다.
