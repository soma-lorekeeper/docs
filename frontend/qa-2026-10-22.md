## 1. 피드백 보내기 — 맞지 않는 안내 문구

`feedback/feedback-provider.tsx` 의 안내 문단과 스타일, 영어 문구를 지웠다. 보고 있던 경로(`page`)는 지금처럼 함께 보낸다. 문구만 없앴다.

## 2. 에디터 — 글꼴 서식이 모든 문서에 같이 적용됨

**원인.** 글꼴·크기·줄 간격은 `documents/editor-prefs.ts` 에서 localStorage 열쇠 하나(`loresentry.editor-prefs.v2`)에 담겼다. 열쇠에 파일·프로젝트 id 가 없고 모듈 전역 스냅숏을 모든 문서 화면이 함께 읽었다. 그래서 한 문서에서 바꾸면 이 브라우저의 모든 프로젝트·문서가 같이 바뀌었다. 근거로 삼은 `DOCUMENT_EDITING_PROPOSAL §2.3`("서식은 문서가 아니라 `user_editor_prefs`")은 `TABLE_AND_LOGIC.md` 로 대체되면서 테이블이 생기지 않았고, 임시였던 브라우저 저장이 그대로 굳었다.

**고친 것.** 서식을 본문 JSON 맨 위 `doc` 노드의 속성으로 담는다.

```json
{"schema_version": 1,
 "doc": {"type": "doc",
         "attrs": {"font": "nanum-myeongjo", "fontSize": 12, "lineHeight": 1.78},
         "content": [...]}}
```

- **서버 변경이 없다.** content 의 `validateBody` 는 노드·마크 종류만 허용 목록으로 보고 `attrs` 는 보지 않는다. `body_json` 은 JsonNode 그대로 JSONB 에 들어간다. `schema_version` 도 그대로 1이다.
- 서식을 바꾸는 것도 본문 편집이다. 저장·revision·버전 기록에 실리고 ⌘Z 로 되돌아간다. 잠긴 문서에서는 바꿀 수 없다.
- 서식이 없는 문서(지금까지의 모든 문서와 새 문서)는 이 브라우저에 예전에 저장해 둔 값으로 보인다. 그 값은 이제 **읽기만** 한다. 그래서 배포 직후 화면은 그대로이고, 한 문서에서 바꾼 서식이 다른 문서로 번지지 않는다. 값이 없으면 토큰 기본값(Pretendard · 10.5pt · 1.5)이다.
- 에디터는 서식 속성이 비어 있으면(null) 적지 않는다(`documentJSON`). 손대지 않은 문서는 예전과 같은 모양으로 저장돼 버전 비교·병합이 바뀐 것으로 보지 않는다.
- 블록 배열로 본문을 다시 만드는 곳(`bodyFromBlocks`)이 `doc.attrs` 를 이어받는다. 저장 충돌 3-way 병합(`merge-text.ts`)은 공통 조상에서 서식을 바꾼 쪽을 따른다. 그래프 최신화의 줄 편집(`graph-refresh/merge.ts`)과 설명 덧붙이기(`api/refresh-proposals.ts`)는 원래 문서의 서식을 지킨다.
- 버전 복원·최신 버전 불러오기는 `setContent` 가 내용만 바꾸고 `doc` 속성은 두므로, 같은 트랜잭션에서 속성도 맞춘다(`replaceDocument`).

| 파일 | 역할 |
|---|---|
| `documents/document-format.ts` | 서식 값 목록, `formatOf(doc, fallback)`, 브라우저 값 읽기(옛 `editor-prefs.ts`) |
| `documents/editor/formatted-document.ts` | `doc` 노드 전역 속성, `setDocumentFormat`, `replaceDocument`, 빈 속성 지우기 |
| `documents/document-view.tsx`, `editor-toolbar.tsx` | 본문에서 서식을 읽어 CSS 변수로, 툴바 선택을 에디터 트랜잭션으로 |

**남은 것.** 새 문서는 서식 없이 만들어져 브라우저 값으로 보인다. 원고마다 같은 글꼴을 쓰는 작가가 많으면 "새 문서 서식 기본값" 설정을 따로 두는 것을 생각할 수 있다.

## 3. 즐겨찾기 — 새 문서의 별이 그래프에 보이지 않음

**원인.** 데이터 문제가 아니었다. 그래프는 content RDB 에서 휴지통 밖의 모든 문서를 노드로 받고, 즐겨찾기 질의도 따로 갱신된다. 별은 분류 아이콘과 같은 크기 기준을 썼다. 화면 반지름이 9px 미만인 노드에는 별을 그리지 않았다(`engine/graph-2d.tsx`). 노드 반지름은 관계 수로 커진다. 관계가 없는 새 문서는 늘 가장 작은 노드(6)라서 화면 맞춤 배율(1 안팎)에서는 별이 그려지지 않았다. 시드의 즐겨찾기 "12화"도 93% 배율에서는 별이 없었다.

**고친 것.** 즐겨찾기 노드에는 크기와 상관없이 별을 그린다. 노드가 작을 때는 기준 크기(화면 8.55px)보다 작아지지 않게 한다. 분류 아이콘은 지금처럼 작은 노드에서 감춘다.

## 4. 설정 — 불필요한 변경사항 알림

`design-system/primitives/save-bar.tsx` 의 동작을 바꿨다. 프로젝트 설정과 계정 설정이 같이 쓴다.

| 상태 | 전 | 후 |
|---|---|---|
| 바뀐 것 있음 | 아이콘 + "저장되지 않은 변경사항" + 취소·변경사항 저장 | 취소 · 변경사항 저장 단추만(오른쪽 정렬, 배경 없음) |
| 저장 중 | "설정을 저장하고 있습니다" + 저장 중… | 취소(꺼짐) · 저장 중… |
| 저장됨 | "설정이 저장되었습니다" 막대 | 아무것도 없음 |
| 실패 | 이유 + 다시 시도 | 그대로 |

`SaveBarState` 에서 `saved` 를 뺐다. `copy` prop 은 실패 문구만 받는 `errorCopy` 가 됐다. 저장하지 않고 탭을 닫을 때의 확인 대화상자는 그대로다.

## 5. 검색

**하이라이트.** 라이트 테마의 `diff-modify-bg`(#eaf0f2)는 결과 목록 바탕(`surface-sunken`)과 거의 같았다. 그래서 1px 고리만 보여 글자 둘레에 상자를 그린 것처럼 읽혔다. 지금은 고리를 빼고 `diff-modify` 20% 바탕(`color-mix`)만 깔며 굵기도 바꾸지 않는다. 행의 스니펫은 `text-secondary` 로 물러나 제목과 일치 구간이 먼저 읽힌다. 문서 안 찾기(`.lk-find-match`)는 바꾸지 않았다.

**정렬.** 결과 위에 `관련도순`(서버 순서: 제목 완전 일치 → 제목 부분 일치 → 본문, 동률은 최근 수정) · `최근 수정순` · `이름순`(언어별 Collator, 숫자 인식 — "2화" 가 "10화" 앞)을 `Segmented` 로 둔다. 결과가 50개 상한이라 화면에서 정렬한다. 서버 변경이 없다.

**메타데이터.** 행마다 다음을 보인다.

- 제목 줄 오른쪽: 마지막 수정(상대 시각, 툴팁에 날짜)
- 아래 줄: 분류 · 에피소드 · 잠김 · 즐겨찾기

잠김은 파일 트리, 즐겨찾기는 즐겨찾기 질의에서 온다. 둘 다 사이드바가 이미 불러 둔 캐시라 요청이 늘지 않는다. 글자 수까지 보이려면 content 검색 응답과 gateway `ContentDtos.Hits` 둘 다에 `char_count` 를 더해야 해서 이번에는 넣지 않았다.

## 6. 사용 가이드

한 문장짜리 절이 대부분이었고, 실제와 다른 곳도 있었다.

- 메모가 "자동 저장"으로 적혀 있었다. 실제로는 저장 단추나 ⌘Enter 로만 저장된다.
- 검색 설명이 정렬이 생기기 전 내용이었다.
- 그래프 최신화, 탭·창 나누기, 설정에 대한 주제가 없었다.

기능 코드에서 화면 문구와 동작을 모아(라벨은 `t()` 원문 기준) 한국어·영어를 함께 다시 썼다.

| 주제 | 절 |
|---|---|
| 작업공간 시작하기 | 새 프로젝트, 카드, 사이드바 구성, 첫 원고, 처음 안내 다시 보기 |
| 탭과 창 나누기 (새) | 탭, 창 나누기, 단축키 표, 배치 복원 |
| 파일과 속성 문서 | 분류 폴더, 만들기, 옮기기·즐겨찾기, 속성, 관계와 설명, 저장 상태 |
| 원고 작성 | 에피소드, 가져오기, 문서별 글꼴과 서식, 찾기·바꾸기, 글자 수, 충돌, 잠금, 내보내기, 버전 기록 |
| 검색과 그래프 | 검색(정렬·메타데이터·한계), 그래프, 노드 찾기, 필터와 에피소드 |
| 그래프 최신화 (새) | 시작(지금은 미리보기 단계임을 밝힘), 검토, 반영 확정, 나중에 마저 하기 |
| 메모와 타임라인 | 작품 메모, 메모 패널, 메모 저장, 타임라인 |
| AI 챗 | 바꾸지 않음(#62 의 변경만 반영) |
| 휴지통과 복원 | 이동, 복원, 영구 삭제, 에피소드 폴더 삭제 |
| 설정과 계정 (새) | 프로젝트 설정, 테마와 언어, 계정, 계정 삭제, 피드백 |

절 본문은 빈 줄로 문단을, `- ` 로 시작하는 줄로 글머리 목록을 쓸 수 있다(`help/guide-parts.tsx` `SectionBody`).
